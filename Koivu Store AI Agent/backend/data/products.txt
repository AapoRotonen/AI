KOIVU STORE — PORTFOLIODEMO
===========================

Koivu Store is a software portfolio demonstration, not a real seller. The public sample catalogue is frontend/catalog.json. Product descriptions, materials, prices, colours, sizes, and availability are illustrative sample data. The variant list does not report a live warehouse or reserve stock.

TILAUKSET, MAKSUT JA TOIMITUS
=============================
The site can save an unpaid synthetic demo order to a signed-in demo account. It does not charge a payment, send an order to a merchant, create a shipment, or provide live tracking. Shipping and return text in the website is an example service flow, not a real offer, policy, or contractual term. The demo does not accept real purchases, returns, or refunds.

KOOT JA HOITO
=============
Available sizes and product-specific care notes are shown in the public catalogue. Size and care information is sample product content; customers should check a real garment label and seller terms before making an actual purchase.

ASIAKASPALVELU
==============
The chat demonstrates automated product support, optional public web search, and a signed-in demo support-case workflow. It is not a staffed support service and does not perform changes to a real customer account or order.
