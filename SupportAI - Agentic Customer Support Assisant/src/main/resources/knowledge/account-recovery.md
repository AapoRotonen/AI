# Account recovery

Category: account-recovery
Version: 1.0

Use the approved password reset flow first. When a customer no longer controls the registered recovery method, do not change the email address or bypass identity checks based only on a support ticket or a request from someone claiming to be the account owner.

Route recovery cases to senior support for the documented identity verification process. Ask for only the verification details required by that process. Never request a password, full card number, one-time code, or recovery code.

If account security may be compromised, preserve the ticket history and escalate immediately. Do not disclose whether another person has an account.
